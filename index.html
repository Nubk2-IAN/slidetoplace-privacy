Privacy Policy

Last updated: 24 October 2026
Android application: com.nubk2.slidetoplace
Applies to version 0.3.1-test.1 (version code 11).

This policy explains how the current version of Slide To Place handles information, and how information is handled when you contact support or visit this policy page.

Information in the game

The current game works offline and can be played without creating an account or signing in. Game progress and preferences are stored locally on your device. The game does not transmit this local save data to the developer.

This version does not include active advertising, in-app purchases, analytics, crash-reporting services, or account-based cloud synchronization. Interface entries for unavailable services do not provide a working sign-in, advertising, purchasing, or cloud-save service in this version.

Local saves and transfers

You can export a local save to a file you choose and import a compatible save into an empty profile. Exported files remain under your control. They are not automatically uploaded to the developer. If you choose a third-party storage provider or share a file yourself, that provider or recipient handles the copy under its own practices.

Local application data remains on the device until it is removed, for example by clearing the app's storage or uninstalling it. Android automatic app backup is disabled for this version. Exported copies are separate from app storage and must be deleted from their saved locations separately. Keep a copy you need before removing local data; the developer cannot recover a save that was never received.

Local app data is subject to the protections and access controls of your device and operating system. Exported files depend on the protections of the location where you save them; no storage method can be guaranteed completely secure.

When you contact support

If you voluntarily email samasu045329@gmail.com, your email address, message and any attachments you send are processed to respond to your request. Email delivery and storage are handled by the email service provider. This correspondence is separate from game telemetry; the game does not automatically send it.

Please do not send passwords or other unnecessary sensitive information. You may contact the same address to request deletion of support correspondence. If a record needs to be retained to address an unresolved request or a legal obligation, that limitation will be explained when handling the request.

This website and platform services

This policy page is hosted on GitHub Pages. It contains no analytics scripts, advertising scripts, tracking pixels, or embedded third-party media. GitHub may process technical connection information, including IP addresses, when serving the page. See the GitHub General Privacy Statement. Visiting this page is separate from playing the offline game.

Google Play, Android and any services you choose to use may process information independently under their own policies. This policy describes the game and support handling; it does not replace those platform policies.

Changes

This policy describes the version identified above. If a later version introduces services that change how information is handled, the policy will need to be updated to describe those changes. Check the version and update date when reviewing this policy.
